# 聊天标题格式化

将 Codex 聊天标题整理为：

```text
10.29｜项目｜主题
10.29｜主题
```

日期使用实际月、日，`10.29` 只是示例；没有项目依据时省略项目段。

## 使用

在 Codex 桌面 app 中安装并启用此插件后，新建聊天并输入：

```text
按规范格式化当前聊天标题。
```

也可以显式选择 `$format-chat-title`，或者说明要整理的聊天、项目和时间范围。

- 有项目示例：`10.29｜Codin｜修复登录失败`。
- 无项目示例：`10.29｜比较鼠标连接稳定性`。
- 历史聊天优先保留旧标题的有效日期，否则使用聊天创建日期；不会全部改成今天。
- 重复执行保持一致，不叠加日期，不生成空项目段。
- 依赖宿主已有的聊天管理工具完成实际重命名；工具不可用时只给出建议标题。
- 这是按相关请求调用的技能，不会在安装后自动监听、改写所有聊天。

完整安装方式见[插件集合仓库](https://github.com/glcodin-droid/codex-plugins)。

可选的 `skills/format-chat-title/scripts/format_title.py` 使用 Python 3.9+ 标准库，只生成文本，不修改聊天。
